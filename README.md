# Labs-Mobile

Welcome to the `Labs-Mobile` repository! This project serves as a learning sandbox and reference guide for creating presentations and documentation using **Markdown** and **Marp**.

## Repository Structure

### 1. `Markdown`
This directory contains a foundational guide to using Markdown.
- **`markdown.md`**: A quick-reference presentation covering the basics of Markdown. It includes syntax for:
  - Headings
  - Text Formatting (Bold, Italic)
  - Lists (Ordered and Unordered)
  - Links and Images
  - Code Blocks
  - Tables
  - Task Lists

### 2. `MARP`
This directory focuses on creating slide decks and presentations purely from Markdown files using [Marp](https://marp.app/).
- **`marp.md`**: A presentation explaining the Marp ecosystem, its features, and how it compares to traditional tools like PowerPoint or Keynote.
- **`index.html`**: A fully exported HTML presentation generated from the `marp.md` file. It includes all the CSS and structure necessary to view the slide deck directly in your browser.

## Getting Started

- To view the Markdown guide, simply open `Markdown/markdown.md`.
- To see the Marp presentation in action, open `MARP/index.html` in any modern web browser.
